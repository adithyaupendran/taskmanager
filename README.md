# Task Manager

A simple Java desktop application for managing tasks with a graphical user interface and MySQL database integration.

## Description

Task Manager is a GUI-based application built with Java Swing that allows users to create, manage, and track their tasks. The application stores task data in a MySQL database and provides an intuitive interface for task management operations.

## Features

- ✅ Add new tasks with due dates
- 🗑️ Delete existing tasks
- ✅ Mark tasks as completed
- 🔄 Refresh task list from database
- 📅 Date validation (DD/MM/YYYY format)
- 💾 Persistent storage using MySQL database
- 🖥️ User-friendly GUI with color-coded buttons

## Requirements

- Java Development Kit (JDK) 8 or higher
- MySQL Server
- MySQL JDBC Driver (Connector/J)
- IDE (recommended: IntelliJ IDEA, Eclipse, or NetBeans)
